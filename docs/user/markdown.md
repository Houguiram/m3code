# Markdown

Agent replies, plans, and pull request descriptions render GitHub-flavored Markdown. On web and
desktop, markdown file previews use the same renderer.

## Mermaid diagrams

A fenced `mermaid` block renders as a diagram. Use the control on the block to switch between the
diagram and its source. Copy always copies the Mermaid source, including when you copy a selection
that includes a rendered diagram.

On mobile, diagrams appear in chat. The first diagram in a session may take a moment to appear.
